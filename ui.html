예보가 맞는 날에만 녹화

오늘 예보에 선택한 날씨가 한 번이라도 있으면 오늘의 예약 시간대 전체를 녹화합니다. 녹화 시각에 비가 오지 않아도 됩니다.

여러 날씨를 고르면 하나만 맞아도 녹화합니다. 비/눈 예보는 비와 눈 모두에 해당합니다.

읍·면·동을 생략하면 시·군·구 대표 지점 예보를 사용합니다. 지역 좌표는 기상청 지역 목록을 사용하고, 예보는 선택한 제공처에서 받습니다.

한 번 조건을 충족한 날은 남은 일정까지 유지합니다. 이후 예보가 바뀌어도 녹화 중간에 취소하지 않습니다. 이미 지나간 구간은 복원되지 않습니다.

카메라에 적용할 내용

처음 비밀번호를 설정하거나 녹화기에 추가

지원되는 Wisenet/SUNAPI 카메라를 한 대씩 등록합니다. 현재 IP가 ED의 카메라용 랜포트에서 접근 가능해야 합니다.

조회만으로 카메라 설정이 바뀌지는 않습니다.

계정 확인 후 IP 설정으로 이동

IP·아이디·비밀번호를 검증한 뒤 접속 정보만 추가합니다. 기존 카메라는 유지하며 녹화를 자동 시작하지 않습니다. 등록하면 위의 IP 변경 화면으로 이어집니다. 새 주소와 ED의 통신 경로를 확인한 후 적용하세요.
