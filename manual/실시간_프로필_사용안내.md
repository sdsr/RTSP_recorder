# 실시간 보기·프로필·핑 이력 사용 안내

RTSP Recorder v2.3 · 2026-11-06

이 안내는 업데이트 후 사용하는 기능을 설명합니다. 설치·업데이트 절차는 [README](../README.md)를 참고하세요. 코드 업데이트만으로 카메라 설정, 저장된 RTSP 주소, 녹화 시간표가 바뀌지는 않습니다. 기존 IP 포함 파일명·설정 보존·예약 녹화 기능도 유지됩니다.

## 화면 열기

브라우저 방식은 `bash 실행.sh`로 연 뒤 **실시간 · 프로필**을 선택합니다. 데스크톱 방식은 `bash 실행_GUI.sh`로 열고 **실시간 보기 · 프로필 관리** 버튼을 누릅니다. 데스크톱에서 열린 웹 화면은 같은 설정과 녹화 상태를 공유합니다. 다른 창에서 설정을 변경했다면 저장된 설정을 다시 불러오세요.

## 녹화하지 않고 영상 보기

1. 저장된 카메라를 선택합니다.
2. 재생할 프로필을 **저장된 녹화 프로필 그대로**, **2번**, **4번** 중에서 고릅니다.
3. **실시간 재생**을 누르고, 마쳤으면 **재생 중지**를 누릅니다.

한 번에 한 대의 H.264 영상을 재생하며 소리는 재생하지 않습니다. 미리보기는 파일을 만들지 않고 예약 녹화와 별도로 연결합니다. 재생할 프로필 선택만으로 저장된 녹화 주소가 바뀌지는 않습니다. 몇 초 지연이 있을 수 있고, 4K 재생이 버거우면 HD 프로필로 확인할 수 있습니다.

해상도는 수신 영상에서 확인합니다. **재생 FPS**는 브라우저가 실제로 재생한 프레임을 측정한 값으로 카메라 설정 FPS·녹화 파일 FPS와 다를 수 있습니다. 프로필 번호만으로 해상도가 보장되지 않으므로 **현재 프로필 조회** 결과와 구분해서 보세요. 페이지를 떠나거나 재생을 중지하면 미리보기 연결을 종료합니다.

## 지원되는 Wisenet 카메라의 HD·4K 구성

저장된 RTSP 계정으로 카메라의 HTTPS 443 관리 API에 접속합니다. 영상 수신 전용 계정은 변경 권한이 없을 수 있습니다. 지원 API·해상도·프로필 번호 지정 기능을 확인할 수 없는 모델에는 적용하지 않습니다.

1. 카메라를 선택하고 **현재 프로필 조회**로 현재 번호·해상도·프레임률을 확인합니다.
2. 이 녹화기의 녹화와 예약 대기를 중지합니다.
3. **HD / 4K 변경 내용 확인**을 누릅니다. 이 단계는 조회·미리보기입니다.
4. 변경 내용을 확인한 뒤 **선택한 카메라에 적용**을 누릅니다.
5. 필요한 다른 카메라도 한 대씩 같은 순서로 진행합니다.

| 프로필 | 목표 영상 | 역할 |
| --- | --- | --- |
| 2번 | H.264 · 1280×720 · 15fps | HD 수신 |
| 4번 | H.264 · 3840×2160 · 30fps | 4K 수신·기본 프로필 |

장비의 지원 범위를 조회해 2번·4번을 구성하고 기본 프로필을 4번으로 지정합니다. 카메라 IP·계정이나 다른 번호의 프로필을 바꾸는 기능은 아닙니다. 카메라 프로필 변경은 그 카메라를 사용하는 다른 수신 프로그램에도 영향을 줄 수 있습니다.

## 녹화 주소를 4번으로 선택

**카메라의 기본 프로필이 4번이어도 `/profile2/media.smp`는 계속 2번 영상을 받습니다.** 이 프로그램의 녹화 주소는 별도로 지정합니다.

1. 녹화·예약 대기를 중지한 상태에서 카메라를 선택합니다.
2. **이 프로그램의 녹화 프로필**에서 **4번 · 4K 구성용**을 고릅니다.
3. **녹화 주소에 적용**을 누릅니다. 카메라에 4번이 실제로 존재하는지 확인한 후 선택한 카메라의 URL 경로를 저장합니다.
4. 필요한 카메라에 반복한 뒤 설정을 확인하고 예약 녹화를 다시 시작합니다.

```text
HD 수신 경로: /profile2/media.smp
4K 수신 경로: /profile4/media.smp
```

이 기능은 직접 IP 입력으로 저장한 카메라에서 사용합니다. `setup.ini` 방식이라면 장비 설정에서 실제 사용할 카메라 목록을 직접 입력해 저장한 뒤 진행하세요. 선택한 카메라의 경로만 바꾸며 다른 카메라·계정·예약 시간은 유지합니다.

## 변경 기록과 실패 확인

- 카메라 변경 전 설정과 단계별 결과: 설정 파일 옆의 `.camera-profile-backups/`
- 녹화 주소 변경 전 JSON: `.recording-profile-backup_*.json`

백업은 개인 파일 권한으로 저장합니다. 녹화 설정 백업에는 계정·비밀번호가 포함될 수 있으므로 공유하거나 Git에 추가하지 마세요. 변경 중 연결·검증·백업 저장에 실패하면 일부 단계가 적용됐을 수 있습니다. 자동 재시도나 자동 원복은 하지 않으므로 표시된 백업·결과를 확인하고 **현재 프로필 조회**로 장비 상태를 다시 확인하세요.

## 연결 기록과 핑 이력

**연결 기록**에서 카메라별 핑 결과를 확인합니다. Linux UI 프로그램이 실행되는 동안 약 1분 간격으로 저장된 카메라 IP를 검사합니다. 최대 64대를 대상으로 최대 4대를 동시에 검사하며, 프로그램이 꺼진 시간은 검사 결과가 없습니다.

최근 최대 24시간의 결과를 `.camera-ping-history.json`에 `0600` 권한으로 보관합니다. 저장 상한은 32,768개 표본으로, 카메라 수가 많으면 보관되는 기간이 24시간보다 짧아질 수 있습니다. 재시작해도 남은 기록을 다시 읽으며, 카메라 IP를 바꿔도 이전 기록에는 검사 당시 IP가 남습니다.

핑 성공은 해당 IP가 ICMP에 응답했다는 뜻입니다. RTSP 로그인·영상 수신 성공을 보장하지 않습니다. 핑을 차단한 카메라는 영상이 나와도 응답 없음으로 표시될 수 있습니다. UI가 꺼진 시간이나 검사 전 상태를 장애·정상으로 단정하지 마세요. 핑 검사는 NIC·VLAN·LTE·라우팅·카메라 설정을 변경하거나 장비를 재부팅하지 않습니다.

실제 카메라 연결, 모델별 프로필 지원, 실시간 영상 재생은 적용할 장비에서 확인해야 합니다.
