01

프로그램 준비 — 처음 한 번

Ubuntu 바탕화면에 로그인한 뒤 터미널에서 실행합니다. Python 3.8 이상을 사용하며 별도 pip 패키지는 필요 없습니다.

sudo apt update
sudo apt install python3-tk ffmpeg
02

압축을 풀고 녹화 창 열기

배포 폴더에서 터미널을 열고 아래 명령을 실행합니다. 기존 recording.json은 유지하고, 없으면 기본 설정으로 생성합니다.

bash 실행.sh

코드 한 파일만 복사했다면:
python3 record.py --config recording.json --gui

03

장비 선택 → 저장 → 5분 시험

장비 · 저장 위치에서 운영 중인 setup.ini와 영상 저장 폴더를 고릅니다. 설정 저장 · 적용 → 설정 검사를 누릅니다. 한 번만 녹화에서 5분을 지정하고 시험 녹화 시작을 눌러 저장 영상을 확인하세요.

04

실행 아이콘을 만들어 다음부터 클릭

창의 실행 아이콘 만들기를 누르면 앱 메뉴에 ED 카메라 녹화가 등록됩니다. 사용할 때 앱을 열고 예약 녹화 시작을 누릅니다.

아이콘은 현재 폴더를 가리킵니다. 폴더를 옮겼다면 새 위치에서 다시 만드세요.

BEFORE RECORDING

처음 사용할 때 알아둘 점

예약 녹화 중에는 앱 창을 유지하세요.
최소화해도 녹화는 계속됩니다. 창을 닫으면 확인 후 이 창에서 시작한 녹화를 정상 종료합니다. 아이콘 등록이나 앱 실행만으로 녹화가 시작되지는 않습니다.

설정 파일이 여러 개 검색되면?

자동 찾기 결과에서 실제 운영 중인 setup.ini를 고르거나 파일 선택으로 지정합니다. 예: /home/dis/2026busan_sis/config/setup.ini. 폴더명이 2025goomi나 2026_busan이어도 됩니다.

시간과 날짜는 어디에서 바꾸나요?

시간표 · 날씨에서 시간 구간을 추가·삭제하고 날짜를 지정합니다. 매일 반복할 때는 날짜를 비워 둡니다. 5분 시험은 날짜·시간표·날씨 조건과 관계없이 진행합니다.

비가 오는 날만 녹화하려면?

날씨 조건을 켜고 Open-Meteo → 지역 → 비를 선택합니다. 개인용은 API 키나 연락처가 필요 없습니다. 당일 예보에 비 소식이 한 번이라도 있으면 그날의 남은 시간표대로 녹화합니다. 이미 지난 구간은 복원하지 않습니다.

기존 서비스가 녹화 중이라고 나옵니다.

데스크톱 창으로 전환할 때 아래 명령으로 기존 서비스를 중지하고 부팅 자동 실행도 해제합니다. 설정과 저장 영상은 남습니다.

sudo systemctl disable --now goomi-camera-recorder.service

아이콘을 명령으로 등록하려면?

python3 record.py --config recording.json --desktop-install

일반 사용자로 실행합니다. sudo는 필요하지 않습니다. 녹화 창을 시작할 뿐, 부팅 자동 녹화를 등록하지 않습니다.

바탕화면이 없는 서버나 SSH에서도 되나요?

데스크톱 창은 그래픽 환경이 필요합니다. SSH에서는 기존 --ui 브라우저 방식과 SSH 터널을 사용합니다. 로그인 없이 부팅부터 녹화할 때는 기존 systemd 설치 방식을 사용하세요.

브라우저 접속·자동 시작·파일명·저장 정책은 함께 제공된 상세 설명서와 README를 참고하세요. Open-Meteo 이용 조건: 개인·비상업용 무료 API.
