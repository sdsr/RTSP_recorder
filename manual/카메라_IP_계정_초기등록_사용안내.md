# 카메라 IP·계정·초기 등록 사용 안내

RTSP Recorder v2.5 · 2026-11-17

이 안내는 업데이트 후 사용하는 기능을 설명합니다. 설치·업데이트는 [README](../README.md)를 참고하세요. 새 설치의 카메라 IP·계정·날씨 지역은 비어 있으며, 기존 운영 설정과 영상은 유지됩니다. 코드 업데이트만으로 카메라나 허브의 IP·계정·비밀번호를 변경하지 않습니다.

## 화면 열기와 적용 범위

`bash 실행.sh`로 브라우저 화면을 열고 **카메라 IP · 계정**을 선택합니다. 데스크톱 GUI에서는 **실시간 보기 · 프로필 관리**로 같은 설정을 공유하는 웹 화면을 열 수 있습니다.

등록된 카메라의 네트워크·관리자 변경은 현재 **PG-ABS08041402** 모델의 지원 응답을 확인한 경우에만 진행합니다. 관리자 ID 변경은 해당 카메라가 지원할 때만 가능합니다. 초기 비밀번호 등록은 초기 상태와 지원 API를 확인한 장비에만 허용합니다. 모든 제조사·모델을 일괄 변경하는 기능은 아닙니다.

작업 전에 녹화와 예약 대기를 중지합니다. 대상 주소에 기존 `enp2*` 또는 그 VLAN 경로로 직접 접근할 수 있어야 합니다. PC에 IP를 추가하거나 NIC·Netplan·LTE 경로를 변경하는 기능은 없습니다.

## IP 중복 검사 준비

주소 변경과 초기 등록 검사는 `arping`과 원시 ARP 패킷 권한을 사용합니다. 권한이나 도구가 없으면 주소가 비었다고 판단하지 않고 중단합니다. Ubuntu에 필요한 도구가 없다면 운영자가 설치합니다.

```bash
sudo apt install arping libcap2-bin openssl
```

녹화기 폴더에서 먼저 검사합니다.

```bash
bash tools/prepare_camera_admin.sh
```

검사 안내에 따라 권한 준비가 필요한 경우에만 아래 명령을 실행합니다.

```bash
sudo bash tools/prepare_camera_admin.sh --apply
```

이 명령은 검증된 시스템 `arping` 실행 파일에만 `CAP_NET_RAW` 권한을 설정합니다. Python에 권한을 주거나 패키지를 자동 설치하지 않습니다. 일반 녹화 프로그램은 기존 사용자로 실행합니다. 코드 업데이트 과정에서는 이 명령을 자동 실행하지 않습니다.

## 등록된 카메라의 IP 또는 관리자 비밀번호 변경

1. 카메라를 선택하고 **현재 설정 조회**를 누릅니다. 장비 모델·일련번호·MAC과 현재 네트워크를 확인합니다.
2. 주소를 바꾸려면 새 IP·마스크·게이트웨이를 입력하고 **IP 변경 내용 확인**을 누릅니다. 계정을 바꾸려면 실제 사용할 아이디·새 비밀번호·확인 비밀번호를 입력하고 **계정 변경 내용 확인**을 누릅니다.
3. 표시된 대상과 변경 내용을 확인하고 확인란을 선택한 뒤 **백업 후 카메라에 적용**을 누릅니다.
4. 결과에서 장비 재접속 확인과 **녹화기 접속 정보 갱신 여부**를 확인합니다. 확인 후 시험 녹화·재생을 점검하고 예약 녹화를 다시 시작합니다.

정상 확인된 경우에만 선택한 카메라의 녹화기 URL을 갱신합니다. 다른 카메라와 예약 설정은 유지합니다. 센터·NVR·다른 ED의 계정은 자동으로 갱신되지 않으므로, 카메라 비밀번호를 바꿨다면 각 수신 프로그램에도 새 비밀번호를 반영하세요.

## 초기 비밀번호가 없는 새 카메라 등록

1. 같은 초기 IP를 사용하는 카메라가 여러 대이면 **한 대만 ED와 통신하도록 먼저 분리**합니다. 실제 배선·MAC·허브 포트를 확인하세요. 이 화면이 포트 분리나 PC의 임시 IP 설정을 자동 수행하지는 않습니다.
2. **새 카메라 · 최초 비밀번호 등록**에서 현재 IP를 직접 입력하고 **초기 등록 상태 조회**를 누릅니다. 필요하면 ED에 이미 설정된 접속 IP도 입력합니다.
3. 표시된 MAC과 대상 카메라가 맞는지 확인하고, 한 대만 분리했다는 확인란을 선택합니다. 초기 상태가 확인된 카메라의 최초 비밀번호 등록에는 제조사 지정 `admin` 계정을 사용합니다.
4. 새 비밀번호와 확인 값을 입력하고 **최초 등록 내용 확인 → 확인란 선택 → 최초 비밀번호 적용** 순서로 진행합니다.
5. 등록 완료 후 실제 계정·비밀번호와 사용할 프로필을 확인하고 **이 카메라 접속 정보 등록**을 누릅니다. 일반 등록 계정은 자동으로 추측하지 않으므로 직접 입력합니다.
6. 필요한 경우 위의 등록된 카메라 설정에서 고유 IP로 변경합니다. 한 대의 결과를 확인한 뒤 다음 카메라를 연결해 반복합니다.

최초 활성화는 기존 비밀번호를 우회하거나 장비를 공장 초기화하는 기능이 아닙니다. 요청 이후 응답이 끊기면 이미 비밀번호가 적용됐을 수 있으므로 자동 재전송하지 않습니다. 카메라 웹 화면에서 현재 초기 등록 여부를 확인하세요. 프로필 번호만으로 해상도가 보장되지는 않으므로 등록 후 **실시간 · 프로필**에서 실제 설정을 확인합니다.

## 카메라와 허브 포트 대조

**허브 관리**의 표시는 `IP → ED의 ARP 캐시 → MAC → 허브 MAC 학습표`를 대조한 결과입니다. `REACHABLE`은 커널의 최근 도달 상태이고, `STALE`·정적 캐시는 이전 관측 정보입니다. 화면 조회가 새 핑이나 ARP 검사를 수행했다는 뜻은 아닙니다.

같은 IP·MAC이 여러 항목이나 포트에서 관측되면 포트를 확정하지 않습니다. 광·업링크·ED 경로에서 학습된 MAC도 카메라 직결 포트로 판단하지 않습니다. 단일 MAC과 포트가 일치해도 중간 장비가 없거나 IP 중복이 없다는 보장은 없습니다. 대조 결과는 제어할 카메라 포트 목록을 자동 변경하지 않습니다.

포트 제어가 필요하면 실제 배선을 확인한 뒤 별도로 등록·확인합니다. 일반 포트 끄기·재연결은 데이터 통신 제어이며 PoE 전원 차단이나 카메라 재부팅이 아닙니다.

## 결과와 백업 확인

- **변경 완료:** 카메라 변경·재접속·녹화기 정보 반영을 확인한 결과입니다.
- **카메라 변경됨 · 녹화기 정보 확인 필요:** 카메라 변경은 확인했지만 로컬 설정 반영이 끝나지 않았습니다. 현재 카메라 주소·계정과 녹화기 설정을 대조하세요.
- **변경 결과 확인 필요:** 실제 카메라 변경 여부를 확인하지 못했습니다. 같은 요청을 반복하기 전에 현재 장비 상태를 확인하세요.

단계별 결과와 백업은 설정 파일 옆 `.camera-admin-backups/`에 남습니다. 백업에는 인증정보가 포함될 수 있으므로 외부에 공유하지 마세요. 부분 적용 후 자동으로 장비 설정을 원복하지 않습니다. **프로그램 코드를 이전 버전으로 되돌려도 실제 카메라의 IP·비밀번호는 되돌아가지 않습니다.**

이 버전의 소프트웨어 검증과 별개로 실제 카메라 접속, 모델·펌웨어별 응답, 공장 초기화 카메라 여러 대의 연속 설정은 적용할 현장에서 확인해야 합니다.
